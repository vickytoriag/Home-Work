# ДЗ 8. Работа с Scapy

## Описание работы

В рамках данного домашнего задания была выполнена работа с библиотекой Scapy.
Целью задания являлось освоение базовых приёмов отправки сетевых пакетов,
перехвата сетевого трафика и его анализа.

---

## Файлы проекта

- `scapy_analyzer.py` — Python-скрипт для отправки HTTP-запросов,
  перехвата и анализа сетевого трафика
- `traffic.pcap` — файл с перехваченным сетевым трафиком
- `README.md` — описание выполненной работы
- `xss_alert.png` - скриншот всплывающего окна

---

## Пример запуска

Отправка HTTP-запроса:

```bash
sudo python3 scapy_analyzer.py --send http://example.com
```

## Перехват сетевого трафика:
```bash
sudo python3 scapy_analyzer.py --capture google-gruyere.appspot.com --timeout 60 --output traffic.pcap
```

## Результаты

В ходе выполнения работы:

- скрипт корректно запускается и выполняет отправку HTTP-запросов;

- осуществляется перехват сетевого трафика;

- перехваченные пакеты сохраняются в файл traffic.pcap;

- выполнен базовый анализ перехваченных пакетов.

## Проверка XSS в Google Gruyere

В рамках задания была выполнена проверка XSS-уязвимостей
в учебном веб-приложении Google Gruyere.

XSS-уязвимость была подтверждена путём вставки тестового payload
в пользовательский ввод. В результате выполнения payload
в браузере отобразилось всплывающее окно.

![XSS screenshot](xss_alert.png)


## Анализ XSS и сетевого трафика

В рамках задания также рассматривалась работа учебного веб-приложения
Google Gruyere, используемого для демонстрации XSS-уязвимостей.

При выполнении перехвата сетевого трафика было установлено, что
Google Gruyere использует протокол HTTPS. В связи с этим содержимое
HTTP-запросов и ответов, включая возможные XSS-пэйлоады, передаётся
в зашифрованном виде и не может быть проанализировано на уровне сети
с использованием Scapy.

Данный результат соответствует ожидаемому поведению современных
веб-приложений и демонстрирует ограничения сетевого анализа
при использовании HTTPS.

В ходе выполнения задания были получены базовые навыки работы
с библиотекой Scapy, перехвата и анализа сетевого трафика.
HTTPS анализ содержимого HTTP-трафика на уровне сети невозможен без
дополнительных механизмов расшифровки.
